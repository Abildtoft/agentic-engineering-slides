# The Factory Model: How Coding Agents Changed Software Engineering

Addy Osmani, published 25 February 2026.

Osmani frames agentic coding as another rise in software's abstraction level: autocomplete assisted keystrokes, synchronous agents translated prompts under close supervision, and autonomous agents now accept specs and return tested artifacts. The engineer increasingly builds and operates the system that builds the software.

A software factory combines fleets of agents with specs, tools, context, feedback loops, quality control, and repeatable environments. At scale, vague intent multiplies across every run, so specifications, architecture, tests, and problem decomposition become more valuable rather than less.

The unresolved problem is verification. Agents can optimize for tests that encode the wrong behavior, miss constraints outside their context, and overwhelm flaky environments. Human oversight remains the safety system until automated evidence can justify the trust granted.
