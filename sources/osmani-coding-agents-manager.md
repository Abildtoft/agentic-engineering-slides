# Coding Agents Turn Engineers into Managers

Addy Osmani, published 8 January 2026.

As coding agents take on larger tasks, engineers spend less time typing implementation details and more time scoping work, delegating it, monitoring progress, and judging results.

## Key ideas

- Agentic work resembles management: prepare a clear brief, assign ownership, establish checkpoints, and review the outcome.
- High-touch local agents suit ambiguous work that needs rapid dialogue.
- Asynchronous background agents suit well-scoped tasks with clear validation.
- Coordination and verification become the limiting resources as implementation capacity increases.
- Engineers remain accountable for decisions even when an agent performs the work.
