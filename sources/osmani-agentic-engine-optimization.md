# Agentic Engine Optimization (AEO)

Addy Osmani, published 11 April 2026.

Osmani proposes AEO as designing developer documentation and interfaces for autonomous agents as well as humans. Agents often make one or two direct HTTP requests, strip pages to text, and operate under a token budget; navigation-heavy, JavaScript-only, or oversized documentation can become effectively invisible.

The proposed stack covers access control, discovery, capability signaling, parsable content, token visibility, and copy-for-AI affordances. Practical guidance includes clean Markdown endpoints, task-oriented indexes, consistent headings, front-loaded outcomes, compact API pages, explicit capabilities and constraints, and agent-native surfaces such as CLI commands, MCP servers, skills, and AGENTS.md.

Osmani explicitly presents this as practitioner guidance for developer-facing docs, not a universal search standard. Exact crawler behavior and emerging file conventions are time-sensitive.
