# Gemini CLI for Agentic Development

Addy Osmani, published 1 January 2026.

This field guide presents a terminal-based coding agent that combines repository context, tool use, persistent rules, and extensibility. The durable lesson is the interaction model rather than any particular command or product capability.

## Key ideas

- A CLI agent can inspect a repository, edit files, run commands, and validate work inside one feedback loop.
- Project instructions and tool integrations make the agent more useful than a context-free chat interface.
- MCP and related extensions connect the coding loop to external systems and data.
- Product commands and limits are time-sensitive; the lasting pattern is an agent operating directly in the development environment.
