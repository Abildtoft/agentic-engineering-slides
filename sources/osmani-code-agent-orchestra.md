# The Code Agent Orchestra

Addy Osmani, published 26 March 2026.

Osmani's practical multi-agent survey moves from subagents to coordinated teams and then local or cloud orchestrators. The recurring benefits are parallelism, focused context, specialization, isolation, and accumulated project knowledge; the recurring costs are coordination, token spend, conflicting edits, and review load.

The engineering patterns are explicit task decomposition, dependency tracking, peer messaging, file ownership, isolated worktrees, plan approval, bounded retries, dedicated reviewers, model routing, and quality gates. Small focused teams outperform scattered fleets, and multi-agent execution is justified only when work is genuinely separable.

The post also places Conductor in the local-orchestrator tier: parallel agents in isolated worktrees with visual oversight and diff-first review. Its durable conclusion is that generation is no longer the bottleneck; verification and coherent integration are.
