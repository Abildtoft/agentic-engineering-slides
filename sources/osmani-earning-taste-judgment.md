# Earning taste and judgment

Addy Osmani, published 14 July 2026.

Thesis: taste and judgment historically emerged from repeated implementation, debugging, and review work. Agents increasingly perform those repetitions, so engineers—especially juniors—must create deliberate ways to acquire the pattern recognition that used to arrive incidentally.

Osmani recommends reading more code than one generates, keeping a log of agent mistakes, doing selected tasks manually, going deep on one system, separating specification from verification, building rubric-based evals, and calibrating autonomy by risk and reversibility. The durable skill is not solving problems with answer keys but choosing worthwhile problems and judging whether the result is good.

He connects the training problem to the outer loop: agents can investigate, implement, and test, while humans decide, verify, approve, and own. Supervising agents requires the same fundamentals that passive use can allow to atrophy, so deliberate practice becomes part of operating the tools responsibly.
