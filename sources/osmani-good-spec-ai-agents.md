# How to Write a Good Spec for AI Agents

Addy Osmani, published 13 January 2026.

A useful agent specification is concise, testable, and alive. It gives the agent enough product intent and operational detail to make decisions while drawing clear boundaries around what it may change.

## Key ideas

- State the vision, constraints, scope boundaries, relevant commands, and acceptance criteria.
- Ask the agent to inspect and plan before it edits.
- Break large outcomes into modular tasks with observable completion conditions.
- Keep the specification current as implementation reveals new facts.
- Define tiers of autonomy so agents know what they may do, what requires review, and what is prohibited.
