# A Semantic History: How "Vibe Coding" Went from a Tweet to Prod

Andrej Karpathy coined "vibe coding" in February 2025 to describe a playful, intuitive mode of AI-assisted development for weekend projects: "Fully give in to the vibes, embrace exponentials, and forget that the code even exists." Within months, the term migrated into production discourse — and its meaning shifted from creative prototyping to a catch-all (often pejorative) label for any prompt-driven development where humans don't fully verify the output.

## Semantic drift

- **Original framing (Karpathy):** Low-stakes, exploratory, "see if it works" hacking. Explicitly not for production.
- **Current usage:** Any AI-assisted development workflow. Increasingly loaded with skepticism as AI-generated code entered mission-critical systems.
- **Cultural markers:** Collins Dictionary named "vibe coding" Word of the Year 2025. Merriam-Webster chose "slop" instead — spotlighting quality concerns over productivity gains.

## Key data

- **1.7x more bugs** in AI-generated code vs. human-written; **1.4x more critical issues** (CodeRabbit, State of AI vs. Human Code Generation)
- **30% of senior developers** report that editing and auditing AI output offsets their time savings (Fastly survey)
- **~33% of seniors** ship half their code as AI-generated vs. **13% of juniors** (Fastly)
- **2025 incident spike:** measurable increase in global service disruptions during peak AI adoption months

## Notable incidents (2025)

- **AWS:** 13-hour outage; internal AI assistant involved in problematic changes
- **Moonwell:** issued $1.8M in bad debt; possibly AI-related
- **Kimi chatbot:** reliability issues amid aggressive AI-assisted scaling

## Core argument

The article argues the industry must transition from creative "vibing" to disciplined "vibe checks" — rigorous quality gates that treat verification infrastructure as critical as generation velocity. Karpathy himself later refined the concept toward "agentic engineering," implicitly acknowledging the gap between prototype vibes and production rigor.
