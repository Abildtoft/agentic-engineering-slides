# The Future of Agentic Coding

Addy Osmani, published 2 January 2026.

Osmani describes a progression from working synchronously with one coding agent to orchestrating several asynchronous agents. The central engineering question changes from how to write the code to how to get the right code built.

## Key ideas

- A conductor works closely with one agent; an orchestrator coordinates several independent efforts.
- Planning, decomposition, context design, and verification become first-class engineering work.
- Parallel implementation only helps when tasks and ownership boundaries are clear.
- Human attention moves toward intent, tradeoffs, integration, and quality control.
