# Agentic Engineering, Not Vibe Coding

Addy Osmani, published 4 February 2026.

Osmani distinguishes undisciplined “vibe coding,” where generated output is accepted without understanding, from agentic engineering, where AI performs more of the implementation but a human remains accountable for architecture, correctness, and quality.

## Key ideas

- The difference is not which tool writes the code; it is whether engineering judgment and verification remain in the loop.
- Strong fundamentals become more valuable because engineers must recognize plausible but incorrect output.
- Agents can compress implementation time while still requiring explicit constraints, tests, review, and ownership.
- Speed without comprehension creates fragile systems and shifts cost into later debugging and maintenance.
