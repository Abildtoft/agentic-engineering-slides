# Don't Outsource the Learning

Addy Osmani, published 16 May 2026.

Thesis: the default agent workflow optimizes task completion, not skill formation. A bug can disappear while the engineer's mental model remains unchanged, trading long-term capability for short-term speed.

Osmani synthesizes studies showing that passive code generation harms later comprehension while conceptual questioning performs much better. The posture matters more than whether AI is present. He recommends forming a hypothesis before asking, requesting explanations before code, using learning modes for unfamiliar domains, treating output like a junior engineer's PR, occasionally re-deriving generated code, and asking the model to teach the concepts it used.

He proposes tracking two outcomes separately: what shipped and what the engineer learned. Delegation is reasonable for low-value boilerplate, but systems that must be debugged, migrated, secured, or pushed beyond common patterns still require maintained human understanding.
