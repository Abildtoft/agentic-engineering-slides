# AI-Written Code Needs Proof

Addy Osmani, published 7 January 2026.

Generated code makes an existing engineering obligation more visible: a change should arrive with evidence that it works. The burden of proof belongs to the person submitting the change, regardless of who or what produced it.

## Key ideas

- Tests, manual checks, and clear reasoning should accompany generated changes.
- Review depth should scale with risk rather than with whether AI was used.
- Smaller pull requests make intent and correctness easier to inspect.
- Security, product context, and architectural fit still require human judgment.
- Teams need explicit accountability norms; generated output cannot be the responsible party.
