# Agent Skills

Addy Osmani, published 3 May 2026.

Osmani describes skills as workflow modules that encode the senior-engineering work agents tend to skip: surfacing assumptions, specifying, planning, testing, reviewing, limiting scope, and leaving evidence. A useful skill is actionable process with checkpoints and an exit condition, not a general essay placed in context.

Five principles carry the argument: process over prose, explicit rebuttals to common rationalizations, verification as a non-negotiable exit criterion, progressive disclosure of only the relevant instructions, and strict scope discipline. Skills sit beside AGENTS.md, hooks, tools, MCP servers, and session memory in the broader harness.

The goal is not novel engineering practice but portable enforcement of practices teams already know: small reviewable changes, tests as specifications, early quality gates, boring designs, and evidence before completion.
