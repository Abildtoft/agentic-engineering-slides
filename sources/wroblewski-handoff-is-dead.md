# Finally, the Handoff is Dead

Luke Wroblewski, lukew.com, 30 April 2026. A follow-up to "The New Designer-Developer Collaboration" (15 April 2026), in which his team designed, built and launched a website in about three weeks with Intent.

## The argument

- **AI didn't kill the handoff; it sped it up.** Individuals are more productive, so designers, developers and PMs throw more work over the wall, faster.
- **The diagnosis:** "Everyone's productive, but are they aligned?" and "AI tools are making individuals faster, but speed isn't the problem. Cohesion is."
- **Each discipline encodes its own expertise once.** In an Intent workspace, the designer gives the agent the Figma file and breakpoint specs, so the grid is set up once; animation behaviour is configured the same way, so transitions are consistent across everything built there. The developer provides the agent's instruction file, testing approach and Tailwind configuration, so the agent follows the team's coding standards.
- **Inheritance keeps parallel work unified.** Every new workspace inherits that encoded taste, so people working at the same time stay consistent without passing files to each other.
