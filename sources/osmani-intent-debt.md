# The Intent Debt

Addy Osmani, published 5 June 2026.

Osmani distinguishes three debts. Technical debt lives in implementation choices; cognitive or comprehension debt lives in people's eroding mental models; intent debt lives in missing artifacts that should explain goals, constraints, and rationale.

Agents can refactor code and help reconstruct how existing code works, but they cannot recover the original human intent. They can only infer a plausible rationale. As agent count grows, every cold session pays again for whatever intent the team failed to externalize, making part of the orchestration tax an intent-debt tax.

The remedy is selective, load-bearing documentation: specs focused on goals and constraints, concise AGENTS.md guidance for invisible conventions, decision records, and learning files that preserve why an approach was chosen or rejected. Complete documentation is impossible, but the expensive-to-get-wrong decisions must not live only in someone's head.
